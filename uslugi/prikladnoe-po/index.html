Прикладное ПО к прибору

Программы настройки и диагностики, мобильные приложения, сбор данных и панели мониторинга — вместе с прошивкой или под ваш готовый прибор.

КороткоДелаем программы, через которые с прибором работают люди и другие системы: настройка и диагностика с ПК, мобильное приложение, сбор данных в облако и панели мониторинга, сервисные утилиты для производства. Пишем ПО вместе с прошивкой или под ваш готовый прибор — по его протоколу обмена.

Что делаем

01

Программы настройки и диагностики

Настольное ПО для ПК: параметры прибора, калибровка, журналы, обновление прошивки.

02

Мобильные приложения

Работа с прибором по Bluetooth или через облако: показания, управление, уведомления.

03

Сбор данных и облако

Серверная часть: приём данных с приборов, хранение, доступ по ролям, интеграция по API.

04

Панели мониторинга

Веб-интерфейс для парка приборов: карта, графики, тревоги, отчёты.

05

ПО для производства

Утилиты прошивки, тестирования и калибровки приборов на сборочной линии.

06

Интеграция

Обмен с системами заказчика: АСУ ТП, SCADA, учётные и информационные системы.

Вопросы и ответы

Можно заказать только приложение к уже готовому прибору?

Да. Нужно описание протокола обмена прибора или доступ к его документации и образец для отладки. Если протокола нет в документации, разбираем обмен вместе с разработчиками прибора.

Для каких платформ делаете ПО?

Под задачу: настольные программы для ПК, мобильные приложения, веб-интерфейсы и серверная часть для сбора данных. Платформу выбираем на этапе ТЗ — исходя из того, кто и где будет работать с прибором.

Нужно ли включать ПО в реестр российского программного обеспечения?

Если прибор или ПО поставляется по госзакупкам с ограничениями на иностранное ПО, включение в реестр может потребоваться. Реестр ведётся по постановлению Правительства РФ от 16.11.2015 № 1236. Учитываем это требование при выборе компонентов и лицензий.

Как вы защищаете данные, которые собирает прибор?

Шифруем обмен, разграничиваем доступ пользователей, храним данные там, где этого требует заказчик. Если приложение обрабатывает персональные данные, учитываем требования 152-ФЗ при проектировании.

ПО к медицинскому прибору — это отдельная задача?

Да. Если программа влияет на диагностику или лечение, она может сама считаться медицинским изделием, и к её разработке и документации предъявляются отдельные требования. Регистрацию ведёт наш Инженерный центр — med-local.ru.
