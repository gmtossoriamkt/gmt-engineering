# Фактчекинги редактора

Сюда кладутся фактчекинги редактора к статьям контент-плана. Имя файла — номер статьи из `content-plan.csv`: `18.md`, `19.md`.

Агент по расписанию подхватывает файл сам, когда берёт статью с этим номером. Фактчекинг для агента — вторичный источник: каждое его утверждение проверяется по первоисточнику.

Папка на сайт не попадает (исключена в `scripts/build_dist.py`), но репозиторий на GitHub публичный — не кладите сюда персональные данные и коммерческие условия.
